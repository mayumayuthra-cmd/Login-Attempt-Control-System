# Login Attempt Control System

## Project Description
A Python-based login system that restricts access after repeated incorrect password attempts.

## Features
- Username and password authentication.
- Tracks incorrect login attempts.
- Allows a maximum of 3 failed attempts.
- Temporarily locks access after 3 failures.
- Unlocks access after 30 seconds.
- Displays login success and failure messages.

## Technologies Used
- Python
- Time Module
- Hashlib Module

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
py login_attempt_control.py
```
